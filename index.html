1. Problem of interest

1.1 Context

The thyroid gland controls the body’s metabolism, energy and growth, and is removed via thyroidectomies for patients with thyroid cancers, goiters, Graves disease and thyroid nodules. Thyroid cancer accounts for the bulk of cases due to its high prevalence, as the second most common cancer in females between 25 and 49 years old (NCCS, 2026), and almost 95% of cases requiring surgery as an effective treatment option (Gomez-Saiz, 2013). The recurrent laryngeal nerve (RLN) is an important nerve that controls voice, breathing and swallowing functions through activation of the vocalis muscle. It is a key nerve at risk during thyroidectomies due its close positioning posterior to the thyroid (Figure 1), with an injury rate of about 8.2% in Singapore (Soong et al., 2026). The presence of large tumours in thyroid cancer can obstruct the surgeon’s field view of the RLN, increasing the risk of injury.

RLN injuries can be temporary or permanent, with a permanent injury rate of 1%, and can either be unilateral or bilateral. While unilateral RLN injury can cause swallowing difficulties and voice changes (Culp & Patel, 2023), bilateral injury can cause serious complications like respiratory distress (Culp & Patel, 2023). RLN injury can be classified into two subtypes: type I (segmental injury) or type II (global injury). Type I injuries account for 70% of cases, are often caused by clamping, traction, compression or thermal injury, and have the potential to be corrected intraoperatively if the clip, suture, vessel or fibrotic band entrapping the nerve is removed on time (Wu et al., 2014).

Intra-operative nerve monitoring (IONM) systems guide surgical decision making during thyroidectomies through determination of RLN identity and functional intactness, so surgeons can preserve the RLN or to change their operative course accordingly. To date, there is only one IONM system that is widely distributed worldwide — Medtronic’s Neural Integrity Monitor (NIM). Since the RLN controls the vocalis muscle, IONM determines RLN functional intactness by 1) electrical stimulation of the RLN and 2) measurement of the action potential fired by the vocalis muscle as a result of RLN stimulation. 1.2 Overview of problem

1.2.1 Lack of uptake of c-IONM

A key issue in i-IONM is its retrospective nature, as it requires the surgeon to manually switch between their dissection instruments and the stimulator probe to check for RLN function. These checking points are highly dependent on the surgeon’s choice of timepoints and frequency in probing for RLN function, and nerve injury can easily be missed between these isolated checking points. In Singapore, the use of i-IONM shows no statistical difference in the RLN injury rate (Leow et al., 2020). Considering how RLN injury can be prevented with timely intervention (Wu et al., 2014), i-IONM’s inability to allow for early detection of RLN compromise prevents prospective prevention of nerve injury.

A seemingly clear way to this is continuous-IONM (c-IONM), a variation of IONM involving stimulation of RLN through an Automatic Periodic Stimulation (APS) clip electrode that is attached to the vagus nerve, the main branch which the RLN is connected to.

Since this electrode is securely positioned for RLN stimulation throughout the surgery, it is able to automatically stimulate the RLN and provide feedback on the EMG activity of the vocalis muscle every 2 seconds. However, the adoption of this method has been sparse: a study found that although 90.3% of surgeons were familiar with c-IONM, only 9.7% chose to use it (Poveda et al., 2024) even despite the fact that c-IONM has been shown to improve surgical outcomes. c-IONM halved the occurrence of vocal cord paralysis to 4.9% as compared to i-IONM and showed a 30-fold decrease in permanent injury. When asked why they do not use c-IONM, surgeons often quote reasons such as the extra step of dissecting the carotid sheath that cause additional surgical risk and inconvenience to the procedure.

1.2.2 Signal unreliability

Aside from the lack of prospective monitoring of nerve intactness, i-IONM also has a low positive predictive value of 63% (Schneider et al., 2017). A common cause of false negative signals (Figure 3) is ETT displacement (Wu et al., 2014) resulting in improper contact between the vocalis muscles and recording electrodes. False loss of signal creates time wasted in constant checking and troubleshooting to get the correct signal. This often involves re-positioning of the ETT, which can only be done by estimation as the contact point of the electrodes is not visible to the surgeon. This troubleshooting protocol is executed in up to 23% of surgeries, adding 5-10 minutes to total surgery time (Ansari et al., 2024). A survey we conducted with 30 surgeons similarly showed ETT displacement to be among the top 3 technical challenges faced during IONM operation.

We also witnessed the unreliability of signals in our clinical immersions, where high levels of off-field feedback created noisy surgical environments (Figure 4), prompting surgeons to toggle monitoring on and off and further contributing to the workflow burden in manual stimulation of the RLN. This issue is seen in both i-IONM and c-IONM methods which both rely on the signal from the ETT recording electrodes as a measure of nerve function.

1.3 Root cause analysis

The key reason for surgeons’ use of i-IONM instead of c-IONM despite its benefits are manpower and method factors. The manual nature of intermittent stimulation means that it is unable to prospectively detect changes in nerve function to prevent nerve damage, yet c-IONM involves the extra step of dissecting the carotid sheath to clip the electrode onto the vagus nerve, which presents an additional step. Although some surgeons claim that this presents an additional surgical risk, Dr. Anita Baghawi, a Malaysian doctor whom we spoke to who is a big proponent of c-IONM, claimed that this risk is negligible and all surgeons in her hospital undergo their specialty training using c-IONM. In contrast, Singaporean surgeons who have been doing i-IONM their entire surgical careers would find this extra dissection step unfamiliar and unaligned with the workflows that they have worked with for years. One of our clinical mentors, Dr. Szymon Mikulski, mentioned that although the dissection is quick and easy, Singaporean surgeons simply do not associate this step with their thyroidectomy protocols. This reveals that Head & Neck surgeons in Singapore are risk-averse and highly resistant to taking up new solutions that are not aligned with their pre-existing training and ways of performing surgery.

As for signal unreliability, the issue can be broken down into two categories – false loss of signal (LOS) and high levels of noise. LOS stems from three main surface causes (Randolph et al., 2010).


a. Improper contact between ETT recording electrodes and vocalis muscle

When secure contact between the recording electrodes on the ETT and the vocalis muscle is lost, the IONM system is unable to detect EMG signals from the vocalis muscle. This can be caused by ETT displacement during neck extension (5mm downwards to 16mm upwards) for patient positioning (Tsai et al., 2011) and by surgical maneuvers such as traction that cause shifts in the contact between vocal ligaments and the recording electrodes (Krishna & Nataraj, 2012). We have identified ETT electrode displacement to be a key cause of LOS and contributor to troubleshooting difficulty along with high prevalence of ETT displacement in almost every thyroid surgery. Additionally, because the contact surface is not visible to the surgeon, displacement cannot be easily identified and realignment is done purely by estimation.


b. Improper contact during stimulation

Wetness in the surgical field caused by blood and edema could result in improper contact between the stimulating electrode and the RLN, impairing its ability to stimulate the vocalis muscle. Wetness can be reduced by suction, absorbent sponges, and hemostatic agents to remove excess blood.


c. Disconnection of electrodes from interface

LOS from disconnection of electrodes from the interface is unlikely due to the fact that the interface is secured under the operating table, and can easily be checked with disconnections rectified.

The high level of off-field feedback has similar causes to LOS, including the unreliable contact between the ETT electrodes and the vocalis muscle as well as external interference by other medical devices in the operating theatre.

The lack of uptake of c-IONM and signal unreliability are both fundamentally workflow issues. The extra step of carotid sheath dissection creates inertia in uptake of c-IONM, while the insecure positioning of the recording electrodes and inability to easily identify and rectify displacement lead to long troubleshooting time. Enabling surgeons to reliably assess nerve function throughout thyroidectomy, providing timely, actionable feedback while minimising disruptions to existing surgical workflows

2.2. Existing solutions

Since IONM has two main components: the stimulation and recording electrodes, different alternatives have been proposed for each of them. Since there is only one main distributor of IONM (Medtronic), with the only competitor, Inomed’s C2 NerveMonitor, having similar functionalities, we have included experimental methods as part of this competitive analysis.

For intermittent stimulation methods, a stand-alone handheld probe can be mobilised independently from the NIM system, with the surgeon assessing RLN function by visual observation of the cricothyroid muscle instead of an EMG signal from the vocalis muscle (Lawson et al., 2020). However this is still manual, intermittent stimulation. Alternatives to the Medtronic APS electrode for c-IONM have also been developed, such as stimulating attachments to dissection instruments like patches (Oh et al., 2021) and rings (Kim et al., 2020) to enable them to serve dual dissection and stimulation functions, with innate stimulating capability (Chiang et al., 2015). However these have high stimulation artefact and risk accidental dissection instead of stimulation respectively. Other promising methods include stimulating the RLN through the laryngeal adductor reflex (LAR) (Sinclair & Tellez, 2024) and trans-tracheally through the pre-insertion of a Medtronic APS into the ETT (Zhang et al., 2020).

For LAR stimulation (Figure 9), one of the two recording electrodes on the ETT is plugged into a stimulation channel instead of a recording channel, allowing it to act as a stimulating electrode to irritate the mucosa and stimulate LAR, a natural reflex involving the RLN where the vocal cords close to prevent entry of foreign bodies into the trachea.

For trans-tracheal stimulation (Figure 10), the RLN can be stimulated by an APS electrode inserted into the ETT due to its close proximity to the trachea but its risk to surgery is unknown since trials have only been done to pigs. These methods are both promising ways to introduce c-IONM to change-resistant surgeons, but both have their limitations which will be discussed later in this report.

The high occurrence of ETT electrode displacement has also prompted the development of alternative recording electrodes (Figure 11), such as trans-cricothyroid (Alon & Hinni, 2009), transcartilage (Lee et al., 2021) or intramuscular (Li et al., 2020) needle electrodes and postcricoid surface electrodes. Though these are more easily accessible and easy to troubleshoot, they prevent higher risk of trauma with displacement and face impaired accuracy. Supplemented by its established position within existing clinical workflows, ETT electrodes remain the gold standard (Barczynski, 2013).

Given our focus on real-time continuous stimulation of the RLN that can be easily integrated into existing workflows while increasing signal reliability and ease of clinical workflow, and our limited timeline of one year, we have chosen to preserve the ETT as the recording interface, focusing on refining it to improve signal and feedback to surgeons while accommodating c-IONM capabilities.



3. Design specifications

Upon analysis from primary and secondary review, we formed our needs criteria encompassing both must-haves and good-to-haves along with clear justifications and alignment to our problem statement.

Overall, our must-have criteria aim to propose a new mechanism to assess nerve function while providing surgeons a robust system that can both detect and provide corrective actions on how to improve the signal obtained. It also gives surgeons a proactive solution that prevents ETT displacement while preventing disruptions to overall workflows during surgeries.

Along with must-have criteria, our solution hopes to satisfy some good-to-have needs criteria when time permits. This includes having an automatic stimulation of RLN more frequently , supporting the assessment of other essential nerves such as the External Branch of the Superior Laryngeal Nerve (EBSLN) and the ability to introduce IONM mid-surgery.

5. Fabrication and testing of initial prototypes

This project aims to build and evaluate key prototypes that effectively answer our criteria and problem statement as shown. There are two main parts to our prototyping fabrication:

1. Modelling of the problem - To simulate movement of vocal cords, necessary as a testing platform for evaluation of prototype tests

2. Designing solutions - To fabricate solutions that prevent ETT displacement, improve contact area, measure and communicate signals effectively so as to address gaps in current solutions

5.1. Simulation of vocal cords

Referring back to an important concept, the simulation of vocal cord movement is essential as a stimulation of RLN will cause the vocal cord ligaments to adduct, enabling a closure (Figure 13). At rest, the vocal cords remain open.

In our first iteration, we used clay to mimic the texture of the vocal cord ligaments (Figure 14) and adopted a manual method of using tweezers to simulate the closure on a live-sized trachea model (Figure 15).


This iteration helped us understand the size of a vocal cord inside a 3D printed trachea model to scale. However, the material of clay is too stiff and failed to capture the finer structure of vocal cord which also limited the movement. Therefore, a different material for the ligaments was explored.

In the second iteration, the vocal ligaments were replaced with fabricating silicone of ecoflex 00-30 (Figure 16). The anatomical composition of vocal ligaments typically consist of elastin and dense collagen fibres and thus were recommended for a shore hardness of between 00-20 to 00-30, thereby guiding our decision to use the smooth-on ecoflex series (Luizard et al., 2023).

While the texture mimics real vocal ligaments, we had to integrate them together by using toothpick and rubber bands to secure the ligaments with the rest of the model (Figure 17). This helped to seal the gaps and form a proper closing mechanism. Future investigation will include a pneumatic pump to control and identify the amplitude of movements and match the signal of a real vocal cord movement upon stimulation of RLN.

5.2. Types of sensing measurement

Currently, signals from ETT are measured via electromyography (EMG) activity from the movement of vocal ligaments in contact with the recording electrodes. We hope to explore other quantifiable detection methods to assess whether the displacement has occurred. The two possible methods tried were using distance displacement and pressure contact sensors.

Firstly, a flex sensor was attached to the top half of the ETT secured using an adhesive glue (Figure 18). Flex sensor works as a variable resistor whose electrical resistance changes as the bending movement increases. Similarly, we were able to obtain variable readings as the tube was being bent. However, using a flex sensor is limited in its measurement for displacements occurring in the x and y directions and thus this method cannot be implemented on its own.

Next, using a thin-film pressure sensor attached to the recording sites of the ETT (Figure 19), the pressure of contact between the recording surface of ETT and vocal cord muscles can be measured. Through this experiment, we identified the pressure exerted by vocal ligaments to be between 5-15mmHg (Hauser et al., 2024). However, it was difficult to estimate the sensitivity of the pressure at which it detects the closure of vocal cords.

Future interactions will explore a more robust model of the simulation of moving vocal ligaments through lab tests such as hydrostatic or pneumatic pressure control so as to determine its effect on the readings obtained by the pressure sensor. Moreover, thresholds on displacement and pressure values that correspond to a signal loss should be investigated for proper calibration.

5.3. Communication of signals obtained

Having a feedback system that characterises the type of signal produced and identifies the root causes for corrective action will be critical in saving time and reducing distress among surgeons. We aim to communicate this via a ‘traffic light’ mechanism and interface display.

5.3.1 Single bulb

The first iteration involves a feedback where a single light bulb lights when the flex sensor exceeds a certain bending displacement, amounting to 370 threshold (Figure 20). This threshold is arbitrary and will be further optimised. While the interactions in the entire circuit were good, this setup could not tell the scale of unreliable signals.

5.3.2 Multiple bulbs

We progressed to a system design where multiple light bulbs progressively activate as the displacement distances increase from a threshold of between 340 and 380 with increments of 10 (Figure 21). This communicates the extent of displacement that occurred but still lacks in providing useful categorisation of the signal produced.

5.3.3 Traffic Light System

Hence, our final iteration consists of a ‘traffic light’ system (Figure 22) where a green light indicates a good signal with minimal ETT displacement, a yellow signal signals to surgeons that an adjustment of ETT by Xmm is needed while a red signal alerts of a very large ETT displacement, possibly causing loss of contact between vocal cords and recording electrodes.

5.4. Prevention methods of ETT displacement

While methods of ETT displacements are explored, we aim to also look at ways to prevent ETT displacement. Hence, the first way includes the addition of an inflatable cuff to further secure the ETT to the trachea, thereby enhancing surface contact. Having a real to-scale model of the trachea had allowed us to investigate the cuff distance from the electrodes affecting its displacement, though this is an estimate due to varying anatomical structure of patients.

Another way looks at securing the ETT from the top via a head strap which serves as a better alternative compared to current methods of wrapping in terms of promoting stability. However, this method must be complemented with an interface placed at the head strap, which is line to the surgeon's field of view (Figure 23). The surgeons are then able to interpret the signals received through the colour coded system and perform necessary corrective actions.

5.6. Takeaways

5.6.1 Prototyping takeaways

From our prototyping phase, we realised that there are various factors causing ETT displacements such as between the vocal cord tissue and recording electrode, at the top due to bending of the ETT and shifting of the tube from left and right during patient repositioning.

Moreover, accurately simulating the intraoperative environment, including vocal cord movement and ETT displacement, is essential for establishing realistic pressure and displacement thresholds, thereby improving accuracy of our evaluation tests.

This prompted further research into the different types of ETT displacement and their impact on signal unreliability. Studies reported tube rotation alone accounts for approximately 44% of I-IONM failures, while neck extension shifts cause ETT shifters greater than 10mm in 12.7% of taped tubes (Tsai et al., 2011). Furthermore, vertical displacement of 10 mm has been associated with a 43–68% reduction in mean amplitude, while rotational displacement of 45–90° can result in a 22–47% reduction (Aygun et al., 2021).

These findings highlight the importance of incorporating both vertical and rotational displacements into our experimental simulations to establish relevant testing conditions, evaluate sensor sensitivity and determine appropriate displacement thresholds.

5.6.2 User feedback

When gathering feedback on which of the two c-IONM methods using ETT to explore, surgeons were more receptive to the idea of stimulation via the LAR reflex for three reasons.

Surgeons found the feedback due ETT displacements to be useful indicators, but that there may be challenges in characterising false signals due to various contributing factors apart from ETT displacements such as poor contact surface area, noise due to electrical interference, traction etc.



6. Discussion of problems and Project Plans

The exploration of optimising LAR c-IONM will be the main focus of our prototyping for Semester 2, with the main question to explore how the signal will be filtered and analysed to give surgeons easily interpretable feedback, without a neurophysiologist.

While our existing prototyping shows the feasibility of flex sensors and a light-based system to feedback on extent of ETT displacement, it needs to be integrated with a more empirical threshold indicating the amount of electrode displacement that corresponds with LOS and be tested to show its performance in reporting signal quality during different surgical maneuvers in thyroidectomy. This can be done by expanding our vocal cord model to include a mockup of the patient’s neck and head to simulate the repositioning that is performed during surgery.

a. Arduino Code used for pressure sensor


const int pressureSensor1 = A0;
const int pressureSensor2 = A1;


int pressureValue1 = 0;
int pressureValue2 = 0;
int combinedPressure = 0;


void setup() {
 Serial.begin(9600);


 pinMode(pressureSensor1, INPUT);
 pinMode(pressureSensor2, INPUT);


 Serial.println("Dual Pressure Sensor Monitoring");
}


void loop() {


 // Read pressure sensor 1
 pressureValue1 = analogRead(pressureSensor1);


 // Read pressure sensor 2
 pressureValue2 = analogRead(pressureSensor2);


 // Calculate combined reading
 combinedPressure = pressureValue1 + pressureValue2;


 // Display individual and combined readings
 Serial.print("Pressure 1: ");
 Serial.print(pressureValue1);


 Serial.print(" | Pressure 2: ");
 Serial.print(pressureValue2);


 Serial.print(" | Combined Pressure: ");
 Serial.println(combinedPressure);


 delay(100);
}

b. Arduino Code used for traffic light bulb feedback


const int flexPin = A0;


// LED pins
const int greenLED = 2;
const int yellowLED = 3;
const int redLED = 4;


int flexValue = 0;


void setup() {
 Serial.begin(9600);


 pinMode(greenLED, OUTPUT);
 pinMode(yellowLED, OUTPUT);
 pinMode(redLED, OUTPUT);
}


void loop() {
 // Read flex sensor value
 flexValue = analogRead(flexPin);


 // Display reading on Serial Monitor
 Serial.print("Flex Sensor Value: ");
 Serial.println(flexValue);


 // RED LED: Reading above 370
 if (flexValue > 370) {
   digitalWrite(redLED, HIGH);
   digitalWrite(yellowLED, LOW);
   digitalWrite(greenLED, LOW);
 }


 // YELLOW LED: Reading above 350
 else if (flexValue > 350) {
   digitalWrite(redLED, LOW);
   digitalWrite(yellowLED, HIGH);
   digitalWrite(greenLED, LOW);
 }


 // GREEN LED: Reading above 345
 else if (flexValue > 345) {
   digitalWrite(redLED, LOW);
   digitalWrite(yellowLED, LOW);
   digitalWrite(greenLED, HIGH);
 }


 // All LEDs OFF
 else {
   digitalWrite(redLED, LOW);
   digitalWrite(yellowLED, LOW);
   digitalWrite(greenLED, LOW);
 }


 delay(100);
}
